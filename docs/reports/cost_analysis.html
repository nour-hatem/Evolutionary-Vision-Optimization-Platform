6Rationale & Scaling Path

Why we chose this architecture and when to upgrade

Why EC2 On-Demand (t3.micro)?

  • Free Tier eligible — 750 hrs/month for 12 months, effectively free for development
  • Simplicity — Single instance with Docker containers minimizes operational complexity
  • Adequate for demo — Experiments are short (minutes), always-on cost is minimal
  • Checkpoint-ready — Seamless migration to Spot/Fargate without code changes

When to Upgrade

Trigger Action
Experiments > 1 hour each Switch training to EC2 Spot
Need parallel experiments Use AWS Batch + Fargate
Production deployment Add Load Balancer + ASG
Budget constraint Use Fargate Spot (pay per job)
