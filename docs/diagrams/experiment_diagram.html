4Key Design Decisions

Why this architecture supports cost-effective, resilient ML experimentation

💾 External Checkpoints (RDS)

Checkpoints stored in AWS RDS, not local disk. If the instance dies, all state survives. This is what enables Spot instance usage.

🔄 Per-Generation Saves

Checkpoint after every generation ensures maximum 1 generation of lost work. Acceptable trade-off for 70% cost savings on Spot.

📊 Structured Logging

Metrics logged to normalized SQL tables (not flat files). Enables queries, dashboards, and cross-experiment comparison at scale.

🔌 API-Driven Workflow

All operations via REST API. Experiments can be submitted from UI, CLI, or CI/CD pipelines. Fully automatable.
